## Version and interpretation rulings

- AAII v5.0.1 uses a different task set and weighting from v4.3.2. Old index/cost/non-hallucination values have separate historical keys; an unavailable new score is null, never an old score carried into the new ranking.
- FrontierCode-AA 2.0 and old 1.1 use separate metric keys. CAI v2.1 uses FrontierCode-AA2.0, TB4.1 and SWE-Atlas-QnA-AA. AAII currently retains model TB4.0 results. Versions and harnesses are not merged.
- Task time in source seconds is divided by 60 for the minutes column and marked estimated because the aggregate includes inferred components, not end-to-end wall-clock measurement. First-answer waiting and output throughput retain seconds and tokens/second respectively; they are not interchangeable.
- Arena's public rows contain displayed rounded Elo intervals; derived bounds are labeled. Explicit effort mismatches and unspecified-versus-known efforts cannot receive winner highlights. Missing or overlapping Elo intervals also block a definitive best-value claim.
- AA channel prices remain labeled as AA when an official live tariff was not readable. No exchange-rate conversion was fabricated for domestic-only prices. Promotions, cache writes, input tiers and subscription allowances remain separate.
- Parameters are stored as absolute counts only when the source supports the stated definition and precision. Tensor census, model backbone and active compute are not silently combined.
- Publication disagreements for Carbon, Beam, Hy4 and Mistral GA remain explicit with no arbitrarily chosen date. Kimi's 10/23 versus 10/24 dispute also remains unresolved, while downloadable weights are now verified independently.
- Preview/GA, generic aliases, exact checkpoint names and router configurations have distinct identities. Qwen3.8 Max0803 Agent data is not transferred to the 0902 row.
- Existing custom column selections survive; only recognized old default presets migrate to current benchmark columns. Company colors and the four-model limit remain unchanged.
